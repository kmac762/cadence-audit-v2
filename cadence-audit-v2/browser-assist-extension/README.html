Cadence Browser Assist

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Click Load unpacked and select this browser-assist-extension folder.
  4. Pin Cadence Browser Assist to Chrome.
  5. Open a public prospect page and click the extension, then Capture this public page.
  6. Back in the matching V2 audit, use Import Browser Assist captures and select the JSON files from Downloads.

The extension uses temporary activeTab access only after you click it. It does not read cookies, form values, stored passwords, or private browser data.
