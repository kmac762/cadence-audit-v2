Update V2 to rc.14

This release contains the rc.13 finding-title and redirected-link-context changes, plus a version-consistency fix.

After Render redeploys, the top-right badge must report 2.0.0-rc.14 and the footer must report V2 · rc.14. If either remains rc.12, Render is still building an older repository path or commit.

Version guard

The startup release check now validates the package version, browser asset stamp, visible footer label, release manifest, and hashed runtime files together. A mixed release fails the build instead of silently showing an old label.
