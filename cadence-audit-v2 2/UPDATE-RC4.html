Update the V2 test release

Complete release: v2.0.0-rc.4. Do not update V1, DNS, your brand assets individually, or your live audit subdomain.

1. Unzip the package

Double-click the ZIP. It contains a folder named cadence-audit-v2. Keep that name.

2. Upload the whole folder to the V2 repository root

Open the regular GitHub page for kmac762/cadence-audit-v2 (not Codespaces). At the repository's top level, choose Add file > Upload files. Drag the complete cadence-audit-v2 folder into the upload area and commit the files together.

Do not open the existing inner cadence-audit-v2 folder before uploading the whole folder: that would create an extra nested folder.

3. Deploy the V2 service

In Render, select cadence-audit-v2, not the V1 service. If a deployment does not start automatically, select Manual Deploy > Deploy latest commit. Leave the root directory cadence-audit-v2, Dockerfile path ./Dockerfile and build context . unchanged.

Once live, refresh the V2 page and confirm 2.0.0-rc.4. Start a new scan. Old saved reports keep their earlier wording and results.

Hourly limits

The defaults remain 6 scan starts per browser per hour and 12 across the app per hour, with one scan running at a time. A scan that starts and then fails still counts. The error now says which limit was reached and approximately how long remains.

After rc.4 is deployed, the optional Render environment variables are SCAN_LIMIT_PER_SESSION and SCAN_LIMIT_GLOBAL. No setting change is required. An increase does not fix a target site's firewall block.

What to test

First run a previously accessible site. Then try one of the sites that refused requests. Look for honest usable/attempted/skipped coverage, access warnings, search-focused recommendations and a working brief. Do not keep retrying a denied site or disable its security.

This is not a protection bypass. For authorized client sites, a site administrator may need to permit the scanner with a narrowly scoped rule. Without that cooperation, protected prospect pages may require manual inspection.
