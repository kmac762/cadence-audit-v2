# V2 rc.6 - Search-first recommendation language

- Reframes recommendation cards around search visibility rather than general UX.
- Changes the primary explanation label to **Why it matters for search visibility**.
- Changes the solution block to **How Cadence would improve the search opportunity**.
- Adds an explicit **Expected search effect - supported vs. unproven** section.
- Keeps user/accessibility value as a small secondary note only where it is relevant.
- Strengthens the missing-H1 playbook around page-topic relevance and Google's documented title-link inputs without presenting H1 as a standalone ranking factor.
- Refreshes the recommendation language of saved non-Browser-Assist reports at read time, so existing reports use the current reviewed playbook language after deployment without changing their underlying observations or evidence.
- Browser Assist, bot-access checks, rate limits, 403 handling, branding, and scan behavior are otherwise unchanged from rc.5.
