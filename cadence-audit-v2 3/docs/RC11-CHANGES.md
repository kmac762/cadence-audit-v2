# rc.11 - Cadence site-style UX refresh

rc.11 changes presentation, not audit truth or scan behavior.

## Visual changes
- White navigation with the original Cadence Search lockup.
- Deep navy hero with restrained brand-spectrum accents and subtle orbit geometry.
- Light workspace and report cards for easier sales-team review.
- Stronger hierarchy for scan controls, coverage cards, recommendations, evidence, technical QA and dialogs.
- Dark Browser Assist panel and dark footer to preserve the Cadence navy identity.
- Responsive mobile spacing and typography retained.

## Preserved behavior
Content Freshness, Site Health, Search & AI Access, Browser Assist, plain-language sales explanations, deterministic findings, rate limits, partial-scan semantics and review decisions are unchanged.
